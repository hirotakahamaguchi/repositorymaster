# 株式会社MANEXION 稟議システム 導入・運用手順書

| 項目 | 内容 |
|---|---|
| システム名 | 株式会社MANEXION 稟議システム（ringi-system） |
| バージョン | 1.0.0 |
| 対象 | システム管理者 / 導入担当者 |

---

## 1. 動作環境

| 区分 | 要件 |
|---|---|
| サーバー OS | Windows 10/11、Windows Server、Linux、macOS（Node.js が動作する環境） |
| ランタイム | **Node.js 22.13 以上**（24 系推奨）。追加パッケージのインストールは不要（`npm install` 不要） |
| データベース | SQLite（Node.js 組み込み。別途インストール不要）。データは `data/ringi.db` に保存 |
| クライアント | Chrome / Edge / Firefox / Safari の最新版 |
| ネットワーク | 既定ポート 3000（環境変数 `PORT` で変更可） |
| ディスク | 本体 1MB 程度 ＋ データ（添付ファイルは DB 内に保存。1 件 5MB × 最大 5 件/稟議） |

> Node.js は https://nodejs.org/ から LTS 版をインストールしてください。起動時に「SQLite is an experimental feature」という警告が表示されますが動作に影響はありません。

## 2. インストール

1. 納品物のフォルダ（`ringi-system`）を任意の場所に配置します（例: `C:\apps\ringi-system`）。
2. 以下のファイル構成になっていることを確認します。

```
ringi-system/
  server.js            HTTP サーバー（本体）
  backup.js            バックアップ CLI
  package.json
  start.bat            Windows 用起動スクリプト
  backup.bat           Windows 用バックアップスクリプト
  lib/                 業務ロジック・認証・DB・バックアップ
  public/              画面（HTML/CSS/JS）
  test/                自動テスト
  docs/                本ドキュメント類
  README.md            技術者向け README
```

3. 初回起動時に `data/ringi.db` が自動作成され、初期ユーザー・承認ルートテンプレートが投入されます。

## 3. 起動・停止

### 起動
- Windows: `start.bat` をダブルクリック（またはコマンドプロンプトで `node server.js`）
- Linux/macOS: `node server.js`

起動後、ブラウザで **http://localhost:3000** を開きます（他端末からは `http://<サーバーのIPまたはホスト名>:3000`）。

### 停止
起動したウィンドウで `Ctrl + C`（または `start.bat` のウィンドウを閉じる）。

### 環境変数（任意）

| 変数 | 既定値 | 内容 |
|---|---|---|
| `PORT` | 3000 | 待ち受けポート |
| `RINGI_DB` | `data/ringi.db` | データベースファイルのパス |
| `RINGI_BACKUP_DIR` | `backups/` | バックアップ出力先 |
| `RINGI_SECURE_COOKIE` | （未設定） | `1` にするとログイン Cookie に `Secure` 属性を付与（HTTPS 運用時） |

例（Windows コマンドプロンプト）: `set PORT=8080 && node server.js`

### サービス化（常時起動）
- Windows: タスクスケジューラで「ログオン時 / 起動時」に `start.bat` を実行、または NSSM 等でサービス登録
- Linux: systemd ユニットで `node /path/to/ringi-system/server.js` を実行

## 5. バックアップと復元

### バックアップ
- 画面: 管理者でログイン →「バックアップ」→「今すぐバックアップを作成」
- コマンド: `backup.bat`（Windows）または `npm run backup`

`backups/backup_YYYYMMDD_HHMMSS/` フォルダに以下がまとめて出力されます。

| ファイル | 内容 |
|---|---|
| `*.csv` | 各テーブルの CSV（UTF-8 BOM 付き、Excel でそのまま開けます） |
| `attachments/` | 添付ファイルの実体 |
| `ringi.db` | データベースの完全コピー（復元用） |
| `manifest.json` / `README.txt` | 件数・日時・説明 |

定期バックアップは Windows タスクスケジューラ / cron に `backup.bat`（`npm run backup`）を登録してください。バックアップフォルダは別ドライブや共有フォルダへコピーしておくことを推奨します。

### 復元
1. サーバーを停止
2. `data/ringi.db` をバックアップ内の `ringi.db` で置き換え（`data/ringi.db-wal`, `data/ringi.db-shm` が残っていれば削除）
3. サーバーを起動

## 6. セキュリティ上の注意

- ログインはログインID + パスワード（scrypt ハッシュ保存）。セッションは HttpOnly Cookie（7 日）
- 連続 5 回のログイン失敗で 60 秒間ロック
- 社外に公開する場合は必ず **HTTPS**（リバースプロキシ: nginx / IIS 等）を前面に置き、`RINGI_SECURE_COOKIE=1` を設定してください
- ユーザーの無効化・パスワード再設定・管理者権限の解除を行うと、そのユーザーは強制的にログアウトされます

## 7. バージョンアップ

1. バックアップを取得
2. サーバーを停止し、`data/` フォルダ以外（`server.js`, `lib/`, `public/` など）を新しいファイルで上書き
3. サーバーを起動（DB のスキーマ変更は起動時に自動で適用されます）

## 8. トラブルシューティング

| 症状 | 対処 |
|---|---|
| `node` が見つからない | Node.js がインストールされていない / PATH が通っていない。インストール後にターミナルを開き直す |
| `EADDRINUSE` で起動できない | ポート 3000 が使用中。`PORT` を変更するか、使用中のプロセスを停止 |
| ログインできない（429） | 失敗が続いたためロック中。約 60 秒待って再試行 |
| パスワードを忘れた | 管理者が「ユーザー管理」→「編集」で再設定。管理者全員が不明な場合は DB を直接操作する必要があるため開発元に相談 |
| 画面が古い表示のまま | ブラウザで `Ctrl + F5`（強制再読み込み） |
| 添付できない | 1 件 5MB まで・1 稟議 5 件まで。上限超過は画面に表示されます |
