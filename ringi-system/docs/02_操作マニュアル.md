# 株式会社MANEXION 稟議システム 操作マニュアル

対象: 申請者 / 承認者 / 管理者

---

## 1. ログイン・ログアウト

1. ブラウザで `http://<サーバー>:3000` を開く
2. ログインID とパスワードを入力して「ログイン」
3. 右上の自分の名前の横にある「ログアウト」で終了

- パスワードを 5 回続けて間違えると約 60 秒ロックされます
- 「パスワード変更」（右上）から自分のパスワードを変更できます（現在のパスワードが必要。変更すると他の端末のログインは無効になります）
- パスワードを忘れた場合は管理者に再設定を依頼してください

## 2. 画面の見かた

| メニュー | 内容 |
|---|---|
| 承認待ち | **あなたの判断が必要な稟議**の一覧。件数がバッジで表示されます |
| 自分の申請 | 自分が申請した稟議（下書き・承認中・差戻し中・完了）。差戻し中の件数がバッジ表示 |
| 一覧 | 自分が関係する稟議すべて（管理者は全件） |
| ＋ 新規申請 | 稟議の新規作成 |
| ルート管理 / ユーザー管理 / バックアップ | 管理者のみ表示 |

一覧では「ステータス」「件名・番号・申請者」で絞り込み・検索できます。行をクリックすると詳細が開きます。

### ステータス
| 表示 | 意味 |
|---|---|
| 下書き | 未申請。申請者のみ閲覧・編集可 |
| 承認中 | 承認ルートを進行中 |
| 差戻し中 | 承認者から申請者へ差し戻された状態。申請者が修正して再申請する |
| 承認済 | すべてのステップを通過し決裁された |
| 却下 | 承認者により却下された（終了） |
| 取下げ | 申請者が取り下げた（終了） |

## 3. 稟議を申請する（申請者）

「＋ 新規申請」を開き、上から順に入力します。

### 3-1. 基本情報
- **件名**（必須）、区分（経費 / 購買 / 契約 / 人事 / IT・設備 / その他）、希望期日、支払先・取引先
- **内容・理由**: 目的・背景・選定理由など、承認者が判断できるように具体的に

### 3-2. 金額・明細
- 「＋ 行を追加」で品目・数量・単価を入力すると金額と合計が自動計算され、**合計が申請金額に自動で入ります**
- 明細を使わない場合は「申請金額」に直接入力できます

### 3-3. 添付ファイル
- 「ファイルを選択」で見積書・仕様書などを添付（**1 件 5MB まで、最大 5 件**）
- 件数は `n / 5` で表示され、上限に達すると追加できません。「取消」で外せます

### 3-4. 承認ルート
- **テンプレートから選ぶ**: 管理者が用意したルートを選択。金額に応じて自動的に適用されるステップがプレビュー表示されます（薄い表示＝金額条件によりスキップ）
- **個別にルートを指定する**: ステップ名・承認方式（誰か 1 人 / 全員）・承認者を自由に組み立てます（承認者権限を持つユーザーのみ選べます）

### 3-5. 申請
- 「**内容を確認して申請 →**」を押すと確認ダイアログが開き、件名・金額・ルート・添付などを確認して「この内容で申請する」で申請されます
- 「**下書き保存**」で保存だけしておき、後から「自分の申請」→ 詳細 → 「編集」「申請する」もできます
- 申請すると最初のステップの承認者の「承認待ち」に表示されます

## 4. 承認する（承認者）

1. 「承認待ち」から稟議を開く（「要対応」タグ付き）
2. 内容・明細・添付・これまでの承認コメントを確認
3. 右側の「承認判断」でコメントを入力し、いずれかを選択

| 操作 | 内容 | コメント |
|---|---|---|
| ✓ 承認する | 次のステップへ進める（最終ステップなら「承認済」） | 任意 |
| ✕ 却下する | 稟議を終了させる。以後の操作不可 | **必須** |
| ↩ 差し戻す | 下記参照 | **必須** |

### 差戻し（任意）
「↩ 差し戻す（任意）」を開き、差戻し先を選びます。
- **申請者**: 申請者に内容の修正・再申請を依頼。稟議は「差戻し中」になり、再申請されると**ステップ 1 からやり直し**
- **前のステップ（例: ステップ 2「部長承認」に戻す）**: 承認済みの前のステップへ戻し、そこから再承認。戻した区間の判断はクリアされ、それより前の承認は保持されます

### 承認方式
- **1 人承認**: そのステップの承認者のうち誰か 1 人が承認すれば進む
- **全員承認**: 全員が承認するまで進まない（1 人でも却下/差戻しすればその判断が優先）

## 5. 差戻しへの対応・再申請（申請者）

1. 「自分の申請」（バッジ表示）から差戻し中の稟議を開く。タイムラインに差戻し理由が表示されます
2. 「編集」で内容を修正 → 「内容を確認して再申請 →」
   （修正不要なら詳細画面の「再申請する」でそのまま再申請）
3. 再申請はステップ 1 から始まり、申請回数（「再申請 2 回目」）が記録されます

## 6. 取下げ・削除

- **取下げ**: 承認中の稟議を申請者が止めるとき。詳細画面 →「申請を取り下げる」（理由は任意）。取下げ後は操作できません
- **下書きの削除**: 詳細画面 →「下書きを削除」

## 7. コメント・履歴

- 詳細画面のコメント欄から、関係者（申請者・ルート上の承認者・管理者）がコメントを投稿できます
- 「タイムライン」に作成・申請・承認・差戻し（差戻し先）・却下・取下げ・コメントが、日時・操作者・コメント付きで記録されます
- 「承認ステップ」には各ステップの承認者ごとの判断（承認/却下/差戻し・日時・コメント）が表示されます
- 添付ファイルはファイル名をクリックするとダウンロードできます

## 8. 管理者の操作

### ユーザー管理
- 一覧のトグルで **管理者 / 承認者 / 有効** を即時切替
- 「＋ ユーザーを追加」「編集」でログインID・氏名・部署・役職・権限・パスワード（新規時は初期パスワード、編集時は再設定）を設定
- **承認者**権限のあるユーザーだけが承認ルートの承認者に指定できます。**管理者**はユーザー管理・ルート管理・バックアップが可能
- 自分自身の管理者解除・無効化、最後の管理者の解除はできません。無効化・パスワード再設定・管理者解除を行うと、そのユーザーは再ログインが必要になります

### ルート管理（承認ルートテンプレート）
- テンプレート名・説明・ステップ（名称 / 承認方式 / 承認者 / **適用最低金額**）を設定
- 適用最低金額を設定すると、申請金額がそれ未満の稟議ではそのステップが自動的にスキップされます（例: 10 万円以上で部長、100 万円以上で社長）
- テンプレートを変更しても、申請済みの稟議のルートには影響しません（申請時点のルートが保存されます）

### バックアップ
- 「今すぐバックアップを作成」で全データ（CSV・添付ファイル・DB コピー）を 1 フォルダに出力。一覧から削除も可能
- テーブルごとの CSV をブラウザで個別にダウンロードすることもできます（Excel でそのまま開けます）
- 復元方法は「導入・運用手順書」を参照
